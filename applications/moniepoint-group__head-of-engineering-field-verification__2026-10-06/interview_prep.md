# Interview prep: Field Verification

## Core stories
- Genkey biometric registration and election identity work.
- MFieldwork mobile data collection.
- Bridge organisation design and API products.

## Questions
- How would you make verification data auditable? Discuss immutable events, clear states, evidence retention and access controls.
- How would you approach route optimisation? Start with data quality, service areas, capacity and measurable operating constraints.
- How would you structure the team? Product, platform/API, field experience and clear manager ownership.

## Questions for Moniepoint
- What are the main sources of verification delay and rework now?
- Which Kenyan regulatory and evidence requirements differ from Nigeria?
