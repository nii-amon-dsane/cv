# Achievements Library

Quantified, sourced achievements drawn from your career. The agent draws from this when customizing artifacts. Add new entries as you remember them or as new wins happen.

Format each entry as:
```
### [Outcome headline] @ [Company] | [Date or range]
- Metric: [specific number, scale]
- Context: [1-2 sentences on what you did]
- Source: [where this is documented — CV, LinkedIn, your memory]
- Verifiable: [yes / no / partially]
```

Mark uncertain metrics with `[estimated]`. The agent will flag `[estimated — verify]` in artifacts.
