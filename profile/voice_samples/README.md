# Voice Samples

Place 3-5 of your writing samples here so the agent can calibrate its voice to yours.

## What counts as a sample

Anything you've written where the voice is authentically you:
- Past cover letters
- LinkedIn posts (yours, not recirculated)
- Blog posts
- Emails to colleagues / recruiters / founders
- Even thoughtful Slack messages capturing how you write informally

## How to add

1. Copy / paste each sample into a markdown file in this directory
2. Name files descriptively:
   - `sample_01_cover_letter_2024.md`
   - `sample_02_linkedin_post_about_mira.md`
   - `sample_03_email_to_recruiter.md`
   - `sample_04_blog_post.md`
   - `sample_05_slack_to_team.md`
3. Add a 1-line header to each explaining the context:
   ```markdown
   # Sample: Cover letter for [role] at [company], [year]
   > Context: [1-line description]
   
   [paste content below]
   ```

## Why this matters

The agent reads `profile/style_guide.md` for rules. Rules are abstract. Samples are concrete proof. Together they calibrate the voice.

Without samples, the agent's voice defaults to "polished but generic" — readable but easy to flag as AI. With 3-5 real samples, the agent picks up:
- Your sentence rhythm
- Your specific vocabulary choices
- How you open paragraphs
- What you choose to emphasize
- Your relationship to formality

## When to update

- After your first 3 applications, the agent will be calibrated well enough that you can stop adding samples
- Add a new sample whenever you write something that feels particularly "you" — helps the agent stay fresh
