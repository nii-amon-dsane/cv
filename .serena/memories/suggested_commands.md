# Application commands
- Create a new folder interactively: `python3 scripts/new_application.py`.
- Render an application bundle: `bash scripts/render_pdfs.sh <application_dir>`.
- Update status: `python3 scripts/update_status.py <application_dir_or_company> <status> [--note "..."]`.
- Regenerate tracker: `python3 scripts/regenerate_tracker.py`.
- Check generated PDF page count: `pdfinfo <file.pdf>`.
